Recommended focus

What stakeholders should do next

P0
Treat mobile web checkout as the first fix

Use checkout satisfaction as the primary leading indicator because it is the strongest actionable touchpoint driver.

P1
Report mobile web separately from app

A blended “mobile” metric hides that app performs near desktop while mobile web is driving detractors.

P2
Prioritize early-life cohorts

Most mobile-web respondents are New or Growing, so improvements here should help acquisition and long-term loyalty.
